# 📖 Overview

This project is a complete **User Management & Inventory Management System** developed using **Flask**, **SQLAlchemy**, and **MySQL**.

The application focuses on implementing real-world backend concepts such as secure authentication, session management, role-based access, CRUD operations, and secure password handling.

Rather than being a simple CRUD application, this project demonstrates how a production-style Flask backend can be structured while following secure development practices.

# ⚙️ Getting Started

## Clone Repository

```bash
git clone https://github.com/akashraval3709-prog/Flask-User-Management-System.git
```

---

## Navigate

```bash
cd Flask-User-Management-System
```

---

## Create Virtual Environment

```bash
python -m venv .venv
```

---

## Activate

Windows

```bash
.venv\Scripts\activate
```

Linux/macOS

```bash
source .venv/bin/activate
```

---

## Install Requirements

```bash
pip install -r requirements.txt
```

---

## Configure Database

Create a MySQL database named

```text
user_management
```

Import

```text
database/schema.sql
```

---

## Run Project

```bash
python app.py
```

Open

```text
http://127.0.0.1:5000
```
